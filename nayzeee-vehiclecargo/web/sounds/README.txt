Custom mission music (optional)

Only used when Config.Music.Mode = 'custom'.
By default the script uses GTA's own Import/Export score from the
player's game files, so this folder can stay empty.

Drop .ogg or .mp3 files here with the names set in Config.Music.Custom:
  start.ogg       contract / sale starts
  delivering.ogg  you have the car, heading home or to the buyer
  attack.ogg      guards, rivals or an ambush are on you
  countdown.ogg   last 30 seconds
  finish.ogg      success sting (plays once)
  fail.ogg        fail sting (plays once)

Only use music you own or have a licence for.
