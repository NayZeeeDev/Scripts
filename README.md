# Scripts

FiveM resources and tools.

| Resource | What it is |
|---|---|
| [`sneaker_box`](sneaker_box/) | Sneaker box prop with a hinged lid that animates open and closed, synced between players |
| [`nayzeee-sneakers`](nayzeee-sneakers/) | Sneaker reselling (in progress): 10 shoe models (107 colourways) as boxed props, three box sizes with a float-in sequence, inspect, wearing, crafting at Dragons Lab tables with materials, fakes and XP, dirt and cleaning, and selling to NPC buyers through a phone app with a handover cinematic. Qbox / QBCore / ESX, ox / qb inventories |
| [`nayzeee-sneakers-clothing`](nayzeee-sneakers-clothing/) | Addon clothing pack for the shoes in nayzeee-sneakers (5 male, 5 female, heels set up). Drop the shoe files in and run `RENAME-CLOTHING.bat` |
| [`nayzeee-sneakers-studio`](nayzeee-sneakers-studio/) | The shoe converter: turns the shoe clothing on a server into box-ready props, icons and a `nayzeee-sneakers-props` resource. Ships inside nayzeee-sneakers as `tools/sneakerkit` (the server runs it itself), and also runs on a PC with a local web UI. Re-runs only convert what changed |
