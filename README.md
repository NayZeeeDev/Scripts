# Scripts

## nayzeee-backpack

Backpacks, purses and job bags for ox_inventory (ESX / Qbox / QBCore / standalone).

- Bags worn as real props, synced through statebags; take-off state survives relogs and restarts
- Purses / pocketbooks loop an upper-body carry pose while the player walks normally
- Counter-style store: camera over the counter, floating bag carousel, try-on view
- Raycast placement (E place, scroll rotate, backspace cancel)
- Admin studio `/bagtune`: character-relative fitting, presets, live storage edits, icon studio
- Job bags with kits, duty checks, police search, wasabi / qb / esx / dispatch integrations

See [`nayzeee-backpack/INSTALL.md`](nayzeee-backpack/INSTALL.md).
