NAYZEEE UI Design

The look of the Nayzeee HUD settings window and HUD panels: dark layered surfaces, hairline borders, one teal accent, the red Close pill and teal / outline / red buttons. All the CSS is in this file. To reuse it, copy the :root tokens and the component classes, and follow the rules in the comment at the top of the file.
