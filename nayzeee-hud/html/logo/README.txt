Put your server logo in this folder and restart nayzeee-hud.

  logo.png, logo.webp, logo.gif or logo.svg are picked up automatically (Config.Watermark.logo = 'auto').
  Any other file name works too: set Config.Watermark.logo = 'yourfile.png'.

A square or wide transparent PNG/WebP around 256 px tall looks best. Animated GIFs play.
Set Config.Watermark.showText = false to show only the logo.
