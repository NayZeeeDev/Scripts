NAYZEEE Icons

Original icons for NAYZEEE scripts. Chamfered corners, the bigger cut on container shapes, a 1.75 stroke and an optional teal accent. Use them like an icon font, as SVG, or straight through NZ.icon(). Click any icon to copy it.

Icon font styleeasiest

Load one stylesheet, then use classes like Font Awesome. Icons take the text colour and font size.

<link rel="stylesheet" href="icons/nz-icons.css">

<i class="nzi nzi-car"></i>
<i class="nzi nzi-cash nzi-lg"></i>

Keep your Font Awesome markup

Load this after Font Awesome. Any FA name we cover shows the NAYZEEE icon instead; everything else keeps working from Font Awesome.

<link rel="stylesheet" href="fontawesome.css">
<link rel="stylesheet" href="icons/nz-icons-fa.css">

<i class="fa-solid fa-car"></i>  → NAYZEEE car

In the UI pack

Every theme already uses this set through the core. Duotone: set --nzi-accent on any parent.

<i data-ic="car"></i>
el.innerHTML = NZ.icon('car');

.panel { --nzi-accent: var(--teal); }

SVG files and sprite

One file per icon in icons/svg/, or a sprite with every icon. The sprite keeps the teal accent option.

<img src="icons/svg/car.svg">

<svg class="nzi-svg"><use href="icons/nz-icons.svg#car"/></svg>
