# Your logo

Drop a PNG in this folder and name it in `Config.UI.logo`. It is read
from here by the bank UI, the ATM screen and the phone app — nothing
else needs changing.

    Config.UI.logo = 'logo.png'

**If the file is not here the built-in wordmark is used instead**, so
there is nothing to break by leaving it alone.

### What works best

- PNG with a transparent background
- Roughly 3:1, around 600 x 200
- Light-coloured artwork — every surface it lands on is dark

This folder is left out of escrow, so you can replace the file
whenever you like without touching anything else.
